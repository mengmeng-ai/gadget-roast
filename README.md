One original one-line roast of an everyday gadget, written by a program to `/output/entry.txt` for the make.fun "One-Line Roast: The Gadget You Use Every Day" bounty.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, standard library only) writes the roast to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).
